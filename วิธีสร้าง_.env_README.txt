วิธีสร้างไฟล์ .env (มองไม่เห็นใน Windows เป็นปกติ)

ไฟล์ .env เป็นไฟล์ซ่อน (ขึ้นต้นด้วยจุด) Windows จะซ่อนไม่ให้เห็น

วิธีที่ 1: ใช้ตัวช่วยสร้าง (ง่ายสุด)
1. ดับเบิลคลิกไฟล์ setup_env.py หรือ สร้าง_ENV.bat
2. วาง DISCORD_TOKEN ที่ได้จาก https://discord.com/developers/applications
3. ใส่ CHANNEL_ID (คลิกขวาที่แชนแนลใน Discord > Copy ID - ต้องเปิด Developer Mode ก่อน)
4. มันจะสร้างไฟล์ .env ให้อัตโนมัติ

วิธีที่ 2: สร้างเองด้วย Notepad
1. เปิด Notepad
2. พิมพ์แบบนี้ 2 บรรทัด:
   DISCORD_TOKEN=ใส่โทเคนตรงนี้
   CHANNEL_ID=ใส่ไอดีแชนแนล
3. File > Save As...
   - ชื่อไฟล์: .env  (พิมพ์จุดนำหน้าเลย)
   - Save as type: All Files (*.*)
   - Encoding: UTF-8
   - เซฟในโฟลเดอร์เดียวกับ bot.py

วิธีที่ 3: ใช้ Command
เปิด cmd ในโฟลเดอร์บอท แล้วพิมพ์:
echo DISCORD_TOKEN=ใส่โทเคน> .env
echo CHANNEL_ID=ใส่ไอดี>> .env

เช็คว่ามีไฟล์จริงไหม
เปิด cmd พิมพ์:
dir /a
จะเห็น .env อยู่ในลิสต์ ( /a = แสดงไฟล์ซ่อน)

ถ้ายังรันแล้วบอกไม่มี TOKEN
แสดงว่าไฟล์ .env ไม่อยู่ที่เดียวกับ bot.py หรือพิมพ์ชื่อผิดเป็น .env.txt
ต้องเป็น .env เท่านั้น ไม่มี .txt ต่อท้าย
